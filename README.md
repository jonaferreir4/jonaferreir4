### Sobre Mim
Graduando em Engenharia de Software na **Universidade Federal do Ceará (UFC)** e Desenvolvedor Full Stack com sólida atuação no mercado corporativo, projetos freelance e projetos de extensão.

Atualmente atuo como **Desenvolvedor Frontend na Kasterweb**, onde sou o responsável técnico pela modernização de plataformas legadas e arquitetura de sistemas escaláveis e *multi-tenant* em produção.

- **Foco de Engenharia:** Clean Architecture, Domain-Driven Design (DDD), Feature-Sliced Design (FSD), concorrência atômica e comunicação em tempo real (WebSockets & WebRTC).
- **Backend:** C# / .NET 8, Node.js / TypeScript, Java 21 / Spring Boot, arquitetura de microsserviços e APIs resilientes.
- **Frontend:** React 19, Next.js 15, TypeScript, TanStack Query v5, Zustand, Tailwind CSS e Shadcn UI.
- **Diferencial:** Experiência com sistemas de missão crítica em produção, desde refatoração profunda de monolitos legados até infraestruturas conteinerizadas com Docker, Redis e Traefik.

### Projetos Pessoais em Destaque

#### <a href="https://github.com/jonaferreir4/apex-auctions" target="_blank">Apex Auctions — Leilões Online com Auditoria Criptográfica</a>
Aplicação full stack de leilões ao vivo com liquidação em custódia e integridade matemática da cadeia de lances.
- **Destaque Técnico:** Concorrência atômica via **locks pessimistas (`SELECT ... FOR UPDATE`)**, integridade auditável por **HMAC-SHA256 encadeado**, lances em tempo real com **Socket.IO** e arquiteturas escaláveis (**Clean Architecture** no backend e **Feature-Sliced Design** no frontend).
- **Stack:** Node.js, TypeScript, Express, Prisma, PostgreSQL, React, Zustand, TanStack Query, Tailwind CSS.
- *[Deploy em Produção (Live Demo)](https://apex-auctions.vercel.app)*

#### <a href="https://github.com/jonaferreir4/dialogue" target="_blank">Dialogue — Plataforma de Comunicação em Tempo Real & WebRTC</a>
Sistema completo de comunicação de alta performance com arquitetura distribuída e concorrência thread-safe.
- **Destaque Técnico:** Mensageria duplex via **ASP.NET Core SignalR (.NET 8)** e **chamadas de áudio e vídeo 1:1 via WebRTC P2P** com sinalização no Hub. Rastreamento de conexões distribuídas via `IConnectionTracker` e gateway Nginx.
- **Stack:** .NET 8, C#, SignalR, WebRTC, React 19, Material UI, Docker.

#### <a href="https://github.com/jonaferreir4/smaller" target="_blank">Smaller — Encurtador de URLs de Alta Performance & Analytics</a>
Microsserviço moderno para encurtamento de URLs, geração dinâmica de QR Code e telemetria analítica de acessos.
- **Destaque Técnico:** Latência de redirecionamento sub-milissegundo com cache distribuído em **Redis 7**, orquestrado via **Traefik Ingress Gateway** em rede isolada Docker.
- **Stack:** .NET Core, C#, Redis 7, PostgreSQL, Traefik v3, Docker Compose, Tailwind.

#### <a href="https://github.com/LearningLabUFC/gestlab-frontend" target="_blank">GestLab — ERP Acadêmico & Gestão Visual (Kanban)</a>
ERP acadêmico que atua como fonte da verdade do LearningLab (UFC), centralizando operações ágeis e inteligência institucional.
- **Destaque Técnico:** Arquitetura **Feature-Sliced Design (FSD)**, cache otimizado com **TanStack Query v5** e sincronização de estado com **Zustand**.
- **Stack:** React 19, Vite, TypeScript, Shadcn UI, Zustand.

#### <a href="https://github.com/jonaferreir4/email-service" target="_blank">Email Service — Microsserviço de Notificações</a>
Microsserviço desacoplado responsável pelo envio transacional assíncrono e resiliente de e-mails.
- **Destaque Técnico:** Integração na nuvem com **AWS SES SDK v2**, isolamento arquitetural e conteinerização Docker.
- **Stack:** Java 17, Spring Boot, AWS SES, Docker, REST API.

#### <a href="https://github.com/jonaferreir4/myevents.net" target="_blank">MyEvents — Gestão de Eventos Acadêmicos</a>
API robusta para gerenciamento de inscrições e emissão automatizada de certificados.
- **Destaque Técnico:** Estruturação estrita em **Clean Architecture**, implementando **Unit of Work**, Repository Pattern, autenticação JWT e FluentValidation.
- **Stack:** C#, .NET Core, Entity Framework Core, PostgreSQL, JWT.
